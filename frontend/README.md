# Agenda — frontend

React + TypeScript + Vite. Veja o README da raiz para rodar o projeto completo.

```
src/
  api/          cliente HTTP (fetch + ProblemDetail) e tipos espelhando os DTOs do backend
  auth/         sessao (token JWT) e AuthContext
  components/   Layout, componentes de UI e lista de agendamentos
  lib/          formatacao (datas, moeda), hooks de agendamentos, navegacao
  pages/        telas do cliente; pages/painel/ telas do profissional
  rotas.tsx     guardas de rota por login e perfil
```
